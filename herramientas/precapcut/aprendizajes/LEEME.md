# Aprendizajes del montaje (se leen ANTES de cada fase)

- `general.md`: reglas para todos los clientes. `<cliente>.md`: solo para ese cliente (mismo slug que `estilos/`).
- **Solo se añade** (nunca se borra): cada entrada con fecha, quién lo dijo y la regla en una línea; si una
  regla nueva corrige otra, se escribe la nueva diciendo cuál sustituye.
- Cuando Gerard, Andrea o Jaume den un tip: se apunta aquí y, si se puede medir (tamaño, posición, color,
  tiempos), se pasa también a `estilos/<cliente>.json` o a los ajustes de `precapcut.py`.
